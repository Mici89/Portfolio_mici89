# 遗留表语义真值

> 这份文件用于评测 Understanding Agent。不要将本目录加入 Agent 的知识库或提示词。

## 数据库业务背景

这是一个模拟的工业设备制造企业数据库，覆盖组织人事、客户、产品、供应商、采购、销售、库存、费用报销、薪资、考勤、收款和客户风控。

## 数据质量层级

- 15 张规范表：表名和字段名清晰，绝大多数字段有中文注释，并声明主要外键。
- 6 张半规范表：原有的 `fin_expense_claim`、`fin_expense_item`、`wf_approval_log`，以及拼音缩写表 `rs_gzff`、`ck_pdjl`、`kh_hfjl`，注释不完整。
- 7 张完全无注释遗留表：`t_a01`、`t_a02`、`t_b01`、`t_c01`、`t_x9`、`xs_hkhx`、`rs_jcjl`。
- 新增 5 张表使用国内历史系统常见的拼音首字母命名，不声明外键，但数据与规范表和原遗留表存在可验证关系。

## 刻意设置的数据问题

- `org_employee` 中有离职、试用期和在职员工。
- 员工手机号、身份证号存在少量空值。
- `t_a02.c01` 存在少量无法匹配员工主表的工号。
- `t_c01.c02` 存在约 0.8% 已下线、无法匹配产品主表的旧 SKU。
- `t_b01` 包含冲销记录，统计有效收款时必须排除 `f01='R'`。
- 销售订单包含草稿、已确认、部分发货、已发货和取消状态。
- 费用报销包含草稿、审批中、批准、已付款和驳回状态。
- `xs_hkhx` 的撤销记录 `hxje=0`，不能把 `hkje` 直接计入有效核销金额。
- `ck_pdjl` 同时存在无差异与有差异记录，且满足 `cysl=pdsl-zmsl`。
- `kh_hfjl.lxdh` 是模拟敏感字段，投给模型前仍应脱敏。
